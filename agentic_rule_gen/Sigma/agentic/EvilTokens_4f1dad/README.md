# EvilTokens

Source: https://www.huntress.com/blog/railway-paas-m365-token-replay-campaign

EvilTokens is a Phishing-as-a-Service (PhaaS) platform used in a large-scale device code phishing campaign targeting Microsoft 365 identities. The campaign leverages infrastructure hosted on the Railway.com PaaS, employs diverse lures potentially generated by AI, and uses multi-hop redirects to bypass email security filters. Attackers use the legitimate Microsoft device code authentication flow to acquire OAuth access and refresh tokens.

- **EvilTokens_C2_IPs** (sigma, high): Keys on specific attacker IPs used as token attack engines for the EvilTokens campaign.

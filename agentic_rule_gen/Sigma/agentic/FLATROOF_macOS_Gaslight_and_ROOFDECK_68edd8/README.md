# FLATROOF (macOS.Gaslight) and ROOFDECK

Source: https://www.sentinelone.com/labs/dont-call-us-well-call-your-apis-tradertraitor-backdoors-resurface-on-victim-with-no-crypto-ties/

TraderTraitor used fake job-interview coding projects whose weaponized .terraform.lock.hcl files point at typosquatted Terraform provider registries to deliver the ARM64 Rust macOS backdoors FLATROOF (SystemUpdate) and ROOFDECK (iSync), later replaced by a stripped ROOFDECK named loginwindow. FLATROOF harvests browser, terminal, system and keychain data and exfiltrates over Telegram, while ROOFDECK verifies signed commands from a hardcoded HTTPS /app_version endpoint using an embedded RSA public key and resolves C2 via Nostr dead-drop lookups. Detections can anchor on the ~/Library/com.apple.* implant paths, the --type=renderer LaunchAgent masquerade, the pinned mkcert certificate metadata and the custom provider domains.

- **APT_TraderTraitor_ROOFDECK_Oct2026** (yara, high): This rule detects the ROOFDECK backdoor by keying on highly specific strings such as a debug message, a certificate serial number, part of a hardcoded RSA key, and configuration markers.
- **HKTL_Mkcert_TraderTraitor_Dev_Cert_Oct2026** (yara, medium): This rule detects a highly specific certificate subject string generated by `mkcert` and used by TraderTraitor, providing an indicator tied to the actor's development infrastructure.
- **macos_tradertraitor_renderer_masquerade** (sigma, high): This rule detects a specific command-line TTP used by the malware, combining the process name with the `--type=renderer` argument for high precision.
- **macos_tradertraitor_loginwindow_masquerade** (sigma, high): This rule detects process masquerading by identifying when `loginwindow` runs from an illegitimate path, a strong indicator of compromise.
- **macos_tradertraitor_implant_execution** (sigma, high): This rule detects the execution of malware from highly specific and unique file paths used by TraderTraitor for its implants.
- **macos_tradertraitor_gatekeeper_bypass** (sigma, high): This rule keys on the specific command-line arguments used to bypass Gatekeeper for the known malware path, making it a very precise detection.
